O jogador percorre uma pequena cidade como um avatar-comunicador. Ao longo do caminho, encontra situações relacionadas à produção e circulação de informações. Suas escolhas fortalecem ou enfraquecem o sinal de credibilidade. Quanto mais confiável é a comunicação, maior é sua capacidade de conectar a comunidade.
Conceito pedagógico
Território → informação → conexão → confiança → força comunitária
